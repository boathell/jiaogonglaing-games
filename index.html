游戏规则

基本规则

交公粮是一种三人玩的扑克牌游戏，每人18张牌。

玩家可以出单张、对子、三张，但没有顺子、连对、三带一、四带二等组合。

每轮由一名玩家先出，其他玩家必须出相同数量且更大的牌，或选择不出。

当一轮中其他两名玩家都选择不出时，由最后出牌的玩家继续先出牌。

牌型大小

单张：3 < 4 < 5 < ... < K < A < 2 < 小王 < 大王

对子：3 < 4 < 5 < ... < K < A < 2

三张：3 < 4 < 5 < ... < K < A < 2

交粮规则

当一名玩家出完所有牌后，剩余两名玩家中手牌最多的为输家。

输家需要交出手中最大的一张牌给赢家，赢家需要还给输家一张较小的牌。

特殊情况：如果输家有四张同数的牌或大小王，则免交粮。

下一局由输家先出牌。
